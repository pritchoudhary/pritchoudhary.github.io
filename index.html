HOW THE LAB IS BUILT

Show the mechanism.
Keep the limits visible.

Practical first

Multiple applications of the same system. A useful tuning change should explain a different design decision.

Compare and measure

Named references, repeatable stress cases and learning challenges make the trade-offs inspectable.

Clear about validation

Browser models and native Unity work are identified separately. A working browser study is not a validated WebGL player.
