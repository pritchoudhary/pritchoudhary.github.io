WHERE IT FAILS

A null optional field does not prove corruption. This manifest cannot discover which script should replace a missing one. An incomplete export can create false unresolved-reference findings.

TRY IT IN UNITY

In the Unity project, choose Tools → Engineering Lab → Create Scene Health Practice Scene, then Scan active scene. Select and ping a finding to locate its object. To compare counts, turn off Include inactive objects and scan again. The inspector leaves the scene unchanged.

How the scan works and what it cannot prove

Each object has a stable ID, parent, local active flag, and modeled component fields. The analyzer validates the hierarchy, computes inherited active state, applies scope, and evaluates rules. Reference lookup uses the complete manifest even when the scan is limited to a subtree.

Severity filtering happens after detection. Scanned counts expose excluded objects. A missing script type, an unresolved target, and an intentionally inactive object are different kinds of evidence. The inspector never infers that every null field is an error.

This browser prototype uses synthetic manifests. The separate native Editor tool scans loaded GameObjects and serialized properties. Unity 6000.5.2f1 passed 13 batch checks, including an imported prefab with a genuinely missing script. This browser exercise does not parse Unity scene files.
