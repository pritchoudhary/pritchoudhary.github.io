Camera rail

Why does a camera speed up on the same curve? Compare equal time steps with and without distance-based sampling.

Playback pauses when these controls leave view or the tab is hidden.

Dashed curve: original geometry. Solid: edited path. Dots mark eight equal intervals of time. Bunched dots mean slower movement. Display axes use different scales; labelled measurements are in world units.

Edit the handles

Keep endpoints fixed. Try raising P1 by one metre without moving P2, then compare against the dashed original.

Scrub to different times with distance mode off, then turn it on. Equal changes in the curve parameter do not generally travel equal distances; the lookup table estimates which parameter corresponds to the requested distance.

In Unity, choose Tools → Engineering Lab → Create Modern Spline. Select the rail and drag the two Scene-view handles. Attach RailFollower to a separate camera or marker to follow the path in Play mode.
